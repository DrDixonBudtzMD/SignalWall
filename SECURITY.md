# Security Policy

SignalWall is prototype software for personal media viewing. It does not bypass platform access controls, embedding restrictions, authentication, DRM, or browser security policies.

## Reporting

Please report suspected security problems privately to Groundstate Technology LLC before public disclosure when practical.

Do not include credentials, private tokens, copyrighted media dumps, or personal data in public issues.

## Current security posture

- SignalWall is intended to run locally.
- Generic web tiles inherit the security behavior of the browser and the source website.
- Platform embeds may execute third-party code supplied by their respective platforms.
- Do not load untrusted URLs in environments where sensitive browser sessions or credentials are exposed.

This prototype has not undergone a formal security audit.
