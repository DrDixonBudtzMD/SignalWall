# Project Governance

SignalWall is an open-source Groundstate Technology LLC project. Source code is licensed under the repository license so the community can use, study, modify, fork, and redistribute it under those terms.

## Official project stewardship

The official SignalWall repository is stewarded by Groundstate Technology LLC and designated maintainers. Maintainers may review, request changes, merge, defer, or decline contributions based on project scope, reliability, legality, platform compatibility, licensing, security, and maintainability.

## Ownership and contributions

Groundstate Technology LLC retains ownership of Groundstate-created code, documentation, project branding, and other Company-created material, subject to the rights granted by the applicable open-source licenses. Contributors retain copyright in their contributions unless a separate written assignment applies.

Submitting code, documentation, issues, tests, or other contributions does not create employment, partnership, equity, membership interests, royalties, or ownership in Groundstate Technology LLC.

## Media-source responsibility

SignalWall is intended as a multi-source media viewing and research interface. Contributors and users remain responsible for complying with platform terms, copyright law, access controls, privacy obligations, and applicable law. The official project should not intentionally ship mechanisms whose primary purpose is defeating authentication, paywalls, DRM, or access controls.

## Security

Changes that process untrusted URLs, media metadata, transcripts, local files, browser content, or external processes should be treated as security-sensitive. New integrations should minimize privileges and document external dependencies.

## Forks and branding

Forking is permitted under the repository license. Materially modified distributions should use distinct branding and must not falsely represent themselves as official Groundstate or SignalWall releases. See `BRAND_POLICY.md`.

## Stewardship objective

The maintainer's role is to keep the official project coherent, useful, lawful, secure-by-default, buildable, and documented while preserving community freedoms granted by the license.
