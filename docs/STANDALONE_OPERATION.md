# Standalone operation

SignalWall is a local browser application. Feed layout, session imports/exports, notes, and playback controls do not require a Groundstate account, Admin Center, shared identity service, or hosted backend.

Network access is used only when the user deliberately loads third-party media. Those platforms may apply their own authentication and embedding rules; SignalWall does not bypass them.

If saved libraries or team sharing are added later, local single-user operation must remain available. Any organization identity connector must be optional, provider-neutral, and isolated from the media-routing core.
